# Changelog

## 0.2.0 — 2026-08-20

- Added Frontmatter Annex with a two-pane Admin2 YAML editor.
- Added reusable annex storage under `user://data/site-workshop/frontmatter`.
- Added recursive map merging, list replacement, multiple-annex composition,
  and explicit page-versus-annex precedence.
- Added protected Admin API routes for listing, saving, and deleting annexes.
- Added copy-ready page frontmatter guidance to the control center.
- Added conservative slug, YAML-root, reserved-key, path, and atomic-write
  validation.

## 0.1.0 — 2026-08-20

- Introduced the modular Site Workshop control center for Grav 2 and Admin2.
- Added Icon Bench with 20 original, `currentColor`-aware interface icons.
- Added safe custom-pack discovery with strict path and slug validation.
- Added a conservative DOM-based SVG sanitizer.
- Added Twig, Shortcode Core, Admin2, API, and CLI access.
- Documented Frontmatter Annex, Cache Hearth, and Feed Relay as planned modules.
