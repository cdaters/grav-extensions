## Documentation boundary

- Package README: installation, configuration, use, update, troubleshooting.
- Package changelog: released behavior by version.
- Repository docs: cross-package design, testing, release operations, plans.
- Site docs: site content and deployment details; these remain in the site
  repository and must not leak into a general-purpose plugin.
