# Meta Pilot

Meta Pilot 0.1 is now a runnable Grav 2 development release under
`plugins/meta-pilot`.

The first milestone covers canonical URLs, descriptions, robots directives,
Open Graph, social cards, JSON-LD, XML sitemap and robots documents, and
duplicate/missing metadata reports. It observes final public HTML without
rewriting page Markdown and preserves metadata features that are disabled in
its own configuration.

Later milestones can add redirect and broken-link diagnostics, richer schema
profiles, multilingual sitemap indexes, search-engine verification fields,
share-card previews, and optional scheduled report snapshots. Remote crawling
or third-party submission must remain explicit rather than a first-run side
effect.
